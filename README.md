# The Sample Room

A text-free axonometric material library in an elongated wooden drawer. Each file is a solid material sample inside a thick, cloudy acrylic holder with six modeled outer faces and a separate solid core. Materials use a coordinated palette of warm timber, mineral neutrals, muted textiles, and metals. The page starts near the center of the collection.

The case uses solid 18px joined panels with flush corners and a fully modeled metal bar handle and mounting posts. Larger 680 × 340px acrylic holders are spaced at 48px centers. The drawer may continue beyond the viewport; the active sample remains centered as the case travels.

Four solid drawers sit in a wooden cabinet. The acrylic collection opens by default in a close axonometric view. Right-side category icons follow the physical drawer order from top to bottom: solid blocks, stone/finishes, timber/textiles, acrylic collection. Drawers extend fully past the cabinet, including at either end of sample browsing. Select a category or drawer handle to pull that drawer out; the others remain closed and stationary. The camera frames the selected drawer without fitting the entire cabinet on screen. Select it again to close it. Acrylic inspection, saving and browser-local boards work across the three file drawers. The top drawer has a dark fitted foam insert with twelve recessed pockets holding solid timber, stone, cork, concrete and metal blocks. Sample scrolling moves only the selected drawer, leaving the cabinet and closed drawers still. Low drawer fronts allow the acrylic samples to rise above them.

Scrolling sends a wave through the samples and translates the entire drawer so the focused sample stays at a fixed screen position. Orthographic projection keeps parallel edges parallel. Select an exposed sample to inspect its texture. Icon controls save a browser-local board and download it as vector SVG.

Built with HTML, CSS 3D transforms, procedural SVG wood grain, and vanilla JavaScript. No build required. Serve this directory with a static server; GitHub Pages publishes main / repository root.

Use wheel or touch scrolling, arrow keys, Page Up / Down, Home / End, or the previous / next icons. Accessible labels remain without visible copy. Reduced-motion mode removes interpolation and velocity ripples. Material textures are illustrative studies.

# The Sample Room

A minimal axonometric material library in a solid wooden shelf. Four independent pull-outs sit close to the shelf, which remains visible behind the active collection. The taller cases and shelf openings accommodate the samples. Only one collection opens at a time; the others remain still.

The right-hand icons follow the physical shelf order, from top to bottom:

- Foam tray with twelve solid material blocks. Hover or keyboard focus lifts a block and shows its name and finish; click or tap opens inspection.
- Ivory sample box with a raised lid and six slanted bare stone samples. Each has modeled thickness and its own slanted name card. Hover lifts the material and card together, with no acrylic enclosure.
- Sample binder in an ivory case. Three modeled rings hold four turnable pages, with six material swatches per page and popper snap mounts behind each swatch. Right-side arrows or left/right keys turn pages. Hover lifts a swatch to reveal its mounting.
- The original acrylic collection, open by default. Twenty-four thick frosted acrylic holders enclose solid material cores. Scroll or use up/down, Home/End and Page Up/Down to browse. The focused sample stays centered while the rack moves within the case; off-case samples are hidden.

Hover details stay hidden until needed. Click or tap a sample for inspection and saving to a browser-local board. Boards export as vector SVG. The same material catalog is shared across the collections.

HTML, CSS 3D transforms, procedural SVG textures and vanilla JavaScript; no build required. Serve this directory with a static server. GitHub Pages publishes main / repository root. Reduced motion removes animated transitions. Material textures are illustrative studies.

# The Sample Room

A tactile, responsive material cabinet. Pull a handle (or click / press Enter) to reveal timber, stone, textiles, and finish studies. Inspect samples, search the collection, keep a browser-local board, and download that board as a self-contained SVG.

Built with HTML, CSS, and vanilla JavaScript. No build, account, API key, or server required. Material names and procedural textures are illustrative studies, not supplier product listings. Google Fonts enhance the typography; local font fallbacks keep the site usable offline.

## Local preview

Serve this directory with any static server, then open `index.html`. The site also works directly from the file system, subject to browser local-storage restrictions.

## GitHub Pages

Publish the repository root from the `main` branch in Settings → Pages. No build step is needed. Relative asset URLs work under a GitHub Pages project URL.

## Accessibility

Native buttons, labelled drawers, keyboard interaction, modal dialogs, inert closed trays, visible focus states, reduced-motion support, and responsive layouts. Saved selections stay on the current browser/device.
